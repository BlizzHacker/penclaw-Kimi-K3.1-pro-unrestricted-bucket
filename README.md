# penclaw-Kimi-K3.1-pro-unrestricted-bucket

Automatically synced mirror of the Hugging Face model repo
**[audnai/penclaw-Kimi-K3.1-pro-unrestricted](https://huggingface.co/audnai/penclaw-Kimi-K3.1-pro-unrestricted)**.

| | |
|---|---|
| Upstream | https://huggingface.co/audnai/penclaw-Kimi-K3.1-pro-unrestricted |
| Upstream author | `audnai` |
| Upstream access | Gated (manual approval) on Hugging Face |
| Sync | Hourly, via a systemd timer on a private server (`git fetch` from HF, then `git push` here) |
| Refs mirrored | All branches and tags; LFS objects pushed when present |

## Status

The first sync is pending. The mirror needs a Hugging Face token that has been
approved for the gated upstream repo. Until it runs, this repo holds only this
README. Once it does, the contents of this repo become an exact copy of the
upstream default branch, **including its README, which will replace this file**.

## Notes

- This is an unofficial mirror and is not affiliated with `audnai`.
- At the time this mirror was set up, the upstream repo listed only
  `.gitattributes` and `README.md`, with no model weights published.
- GitHub rejects files over 100 MB unless they use Git LFS, and its LFS quota is
  small, so large weight files may not be mirrored here.
- The upstream repo is authoritative. Anything you change here will be overwritten
  on the next sync.
